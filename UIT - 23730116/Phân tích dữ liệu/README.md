# Phân tích dữ liệu / Data Analysis

## 🇻🇳 EDA và dự đoán giá kim cương

**Dự án:** Phân tích thăm dò bộ dữ liệu Diamonds và xây dựng mô hình dự đoán giá.

**Đã làm được**
- Làm sạch dữ liệu từ **53,940 → 53,917 dòng**.
- Phát hiện lỗi/ngoại lệ và tạo biến `volume`.
- Thực hiện EDA, thống kê mô tả và trực quan hóa.
- Phân tích tương quan và ANOVA.
- Xây dựng Linear Regression, Multiple Linear Regression và Polynomial Regression.
- Dùng **Scikit-learn Pipeline**, encoding, scaling và cross-validation.
- Mô hình tốt nhất: **Polynomial Regression bậc 3**, đạt khoảng **R² = 0.9346**, RMSE ≈ **1,015.50 USD** trên test set.
- Chuẩn bị dữ liệu cho dashboard trực quan hóa.

**Học được**
- Quy trình end-to-end từ dữ liệu thô đến mô hình dự đoán.
- Data cleaning, feature engineering, statistical analysis và model evaluation.
- Cross-validation và lựa chọn mô hình có cơ sở thay vì chỉ so sánh một metric.

## 🇬🇧 Data Analysis

**Project:** EDA and diamond-price prediction.

**Built**
- Cleaned **53,940 → 53,917 records**.
- Detected data issues/outliers and engineered a `volume` feature.
- Performed EDA, descriptive statistics and visualization.
- Applied correlation analysis and ANOVA.
- Built linear and polynomial regression models.
- Used **Scikit-learn Pipelines**, encoding, scaling and cross-validation.
- Best reported model: **degree-3 Polynomial Regression**, with approximately **R² = 0.9346** and RMSE ≈ **USD 1,015.50** on the test set.
- Prepared data for dashboard visualization.

**Learned**
- End-to-end data analysis and predictive modeling.
- Data cleaning, feature engineering and statistical reasoning.
- Model selection and evaluation with cross-validation.
