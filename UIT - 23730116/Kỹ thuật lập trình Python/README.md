# Kỹ thuật lập trình Python / Python Programming Techniques

## 🇻🇳 Django REST API quản lý dịch vụ giặt ủi

**Dự án:** Xây dựng RESTful API cho hệ thống quản lý dịch vụ giặt ủi.

**Đã làm được**
- Quản lý khách hàng, dịch vụ, hàng hóa, đơn hàng, hóa đơn và thanh toán.
- CRUD và các nghiệp vụ mở rộng.
- Thanh toán theo hướng **đa hình**.
- Phân quyền người dùng và quản trị viên.
- Tự động sinh mã đơn/hóa đơn.
- Thống kê doanh thu theo khoảng thời gian.
- Xây dựng khoảng **58 REST endpoints**.
- Kiểm thử API bằng Postman và unit tests.

**Công nghệ:** Python, Django, Django REST Framework, SQLite, Postman, Git.

**Học được**
- Thiết kế REST API và tổ chức backend theo module.
- ORM, serializer, viewset, authentication/authorization.
- Viết test cho logic nghiệp vụ.
- Tư duy thiết kế API theo use case thay vì chỉ CRUD đơn giản.

**Điểm nổi bật**
- Project gần với một backend service thực tế: có nghiệp vụ, database, phân quyền, testing và reporting.

## 🇬🇧 Python Programming Techniques

**Project:** A Django REST API for laundry-service management.

**Built**
- Customer, service, inventory, order, invoice and payment management.
- CRUD and business-specific endpoints.
- Polymorphic payment design.
- User/admin authorization.
- Automatic order/invoice numbering.
- Revenue reporting by date range.
- Around **58 REST endpoints**.
- Postman and unit testing.

**Tech:** Python, Django, Django REST Framework, SQLite, Postman and Git.

**Learned**
- REST API design and backend modularization.
- ORM, serializers, viewsets and authorization.
- Business-logic testing and API validation.

**Portfolio value**
- Shows practical backend engineering beyond basic Python programming.
