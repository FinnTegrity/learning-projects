# Thiết kế giao diện người dùng / UI Design

## 🇻🇳 20UIT.SHOP — Website bán nội thất cao cấp

**Dự án:** Thiết kế trải nghiệm và giao diện website thương mại điện tử nội thất.

**Đã làm được**
- Khảo sát người dùng với hơn **80 người**.
- Phân tích nhu cầu, hành vi và kỳ vọng khi mua nội thất online.
- Đi từ **research → wireframe → mockup → high-fidelity UI → website**.
- Thiết kế nhiều luồng và màn hình của website bán nội thất.
- Chú trọng hierarchy, typography, màu sắc, layout và khả năng sử dụng.

**Học được**
- User research và chuyển dữ liệu khảo sát thành quyết định thiết kế.
- Wireframing, UI design, interaction và trình bày prototype.
- Tư duy thiết kế dựa trên người dùng thay vì chỉ tập trung vào “giao diện đẹp”.

**Điểm nổi bật**
- Thể hiện khả năng đi xuyên suốt quy trình **UX research → design → implementation**.

## 🇬🇧 UI Design

**Project:** 20UIT.SHOP — premium furniture e-commerce website.

**Built**
- User research with **80+ respondents**.
- Analysis of online furniture-shopping needs and expectations.
- End-to-end workflow: **research → wireframe → mockup → high-fidelity UI → website**.
- Designed key e-commerce flows and screens.
- Focused on hierarchy, typography, layout and usability.

**Learned**
- User research and evidence-based design decisions.
- Wireframing, interaction design and prototype presentation.
- Designing for usability rather than aesthetics alone.

**Portfolio value**
- Shows the ability to connect **UX research, visual design and implementation**.
