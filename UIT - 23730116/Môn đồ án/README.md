# Môn đồ án / Capstone Project

## 🇻🇳 Ứng dụng web hỗ trợ học tập từ tài liệu

**Dự án:** Xây dựng ứng dụng web chuyển tài liệu PDF/TXT thành nội dung học tập có cấu trúc.

**Đã làm được**
- Upload/kéo-thả tài liệu.
- Trích xuất nội dung từ PDF/TXT.
- Dùng AI để tạo **summary, mindmap Mermaid, flashcards và quiz**.
- Flashcard có điều hướng, hiển thị đáp án và mức độ khó.
- Quiz hỗ trợ trắc nghiệm/điền khuyết và chấm điểm trực tiếp.
- Hỗ trợ lưu/export dữ liệu học tập dạng JSON.
- Thiết kế giao diện web hiện đại, tập trung vào trải nghiệm học tập.

**Công nghệ chính:** Python, Flask, OpenAI API, HTML/CSS/JavaScript, PyPDF2, Mermaid.

**Học được**
- Thiết kế một sản phẩm từ **ý tưởng → kiến trúc → backend → frontend → AI integration → testing**.
- Prompt design và tạo output có cấu trúc bằng JSON schema.
- Xử lý giới hạn context, text extraction và dữ liệu sinh tự động.
- Thiết kế UX cho một công cụ học tập thay vì chỉ xây dựng một demo AI.

**Điểm nổi bật**
- Đây là project thể hiện rõ khả năng kết hợp **software engineering + AI + UX + educational workflow** thành một sản phẩm hoàn chỉnh.

## 🇬🇧 Capstone Project

**Project:** A web application that transforms study documents into structured learning materials.

**Built**
- PDF/TXT upload and text extraction.
- AI-generated **summaries, Mermaid mindmaps, flashcards and quizzes**.
- Interactive flashcard navigation and difficulty levels.
- MCQ/fill-in-the-blank quizzes with immediate scoring.
- JSON-based learning-data export/import.
- A modern, learning-focused web interface.

**Main technologies:** Python, Flask, OpenAI API, HTML/CSS/JavaScript, PyPDF2 and Mermaid.

**Learned**
- End-to-end product development: **idea → architecture → backend → frontend → AI integration → testing**.
- Prompt design and structured JSON outputs.
- Text extraction, context management and generated-content workflows.
- UX design for a real learning workflow instead of a simple AI demo.

**Portfolio value**
- A strong demonstration of combining **software engineering, AI, UX and product thinking** in one project.
