
# Khai thác dữ liệu truyền thông xã hội / Social Media Data Mining

## 🇻🇳 Phân tích cảm xúc và khám phá chủ đề bình luận tiếng Việt

**Dự án:** Xây dựng ứng dụng phân tích dữ liệu bình luận tiếng Việt trên mạng xã hội.

**Đã làm được**
- Làm sạch và chuẩn hóa văn bản tiếng Việt.
- Tách từ bằng `underthesea`, xử lý stopwords và TF-IDF.
- Huấn luyện mô hình **Multinomial Naive Bayes** cho sentiment analysis.
- Phân loại **positive / neutral / negative**.
- Khám phá chủ đề bằng **clustering K-Means** và hỗ trợ phân tích topic.
- Xây dựng giao diện phân tích bằng Streamlit.

**Học được**
- Pipeline NLP từ raw text → preprocessing → feature extraction → model → visualization.
- Xử lý đặc thù của dữ liệu tiếng Việt.
- Kết hợp supervised learning và unsupervised learning trong cùng một bài toán.

**Điểm nổi bật**
- Có mô hình, dữ liệu huấn luyện, vectorizer đã lưu và giao diện để người dùng đưa dữ liệu mới vào phân tích.

## 🇬🇧 Social Media Data Mining

**Project:** Vietnamese social-comment sentiment and topic analysis.

**Built**
- Vietnamese text cleaning and tokenization.
- TF-IDF feature extraction and a **Multinomial Naive Bayes** sentiment model.
- Positive/neutral/negative classification.
- **K-Means clustering** for topic exploration.
- A Streamlit-based analysis interface.

**Learned**
- End-to-end NLP pipelines.
- Practical Vietnamese text processing.
- Combining supervised and unsupervised machine learning.

**Portfolio value**
- Demonstrates practical NLP skills rather than only model training in a notebook.
