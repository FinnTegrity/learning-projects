# Lập trình hướng đối tượng / Object-Oriented Programming

## 🇻🇳 Bài tập hình học với Java

**Dự án:** Xây dựng chương trình xử lý các đối tượng hình học bằng Java.

**Đã làm được**
- Thiết kế lớp trừu tượng `Geometry` và các lớp `Point`, `LineSegment`, `Circle`, `Triangle`, `Rectangle`.
- Áp dụng kế thừa và ghi đè phương thức.
- Tính chu vi, diện tích và kiểm tra tính hợp lệ của đối tượng.
- Một số bài toán hình học có kiểm tra quan hệ giữa các đối tượng.

**Học được**
- Encapsulation, abstraction, inheritance và polymorphism.
- Thiết kế class theo trách nhiệm.
- Tách logic tính toán khỏi phần nhập/xuất dữ liệu.

## 🇬🇧 Object-Oriented Programming

**Project:** Java-based geometric object modeling.

**Built**
- An abstract `Geometry` class with `Point`, `LineSegment`, `Circle`, `Triangle` and `Rectangle` implementations.
- Inheritance and method overriding.
- Area/perimeter calculations and object validation.
- Additional geometric relationship checks.

**Learned**
- Encapsulation, abstraction, inheritance and polymorphism.
- Responsibility-oriented class design.
- Separating calculation logic from input/output concerns.
