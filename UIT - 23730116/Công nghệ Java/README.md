
# Công nghệ Java / Java Technology

## 🇻🇳 Ứng dụng quản lý trung tâm dạy thêm + Quiz Card

**Dự án:** Xây dựng ứng dụng desktop quản lý trung tâm dạy thêm bằng Java.

**Đã làm được**
- Quản lý học viên, giáo viên, môn học, lớp học, đăng ký và học phí.
- Đăng nhập và phân quyền **Admin/Staff**.
- Tra cứu, lọc dữ liệu và báo cáo doanh thu.
- Kết nối MySQL bằng JDBC và đóng gói ứng dụng thành JAR.
- Thực hành thêm một ứng dụng Quiz bằng **Swing + CardLayout**.

**Học được**
- Java OOP, Swing, JDBC, Maven.
- **MVC, DAO, Service layer** và tổ chức source code theo module.
- Áp dụng **Strategy** và **Observer pattern** trong bài toán nghiệp vụ.
- Thiết kế database quan hệ và xây dựng ứng dụng desktop có quy trình tương đối hoàn chỉnh.

**Điểm nổi bật**
- Không chỉ viết code Java cơ bản mà đã đi tới một ứng dụng có UI, database, authentication, business logic và packaging.

## 🇬🇧 Java Technology

**Project:** A Java desktop application for managing a tutoring center.

**Built**
- Student, teacher, subject, class, enrollment, attendance and tuition management.
- **Admin/Staff** authentication and authorization.
- Search/filter features and revenue reporting.
- MySQL integration through JDBC and Maven-based packaging.
- A separate Swing quiz application using **CardLayout**.

**Learned**
- Java OOP, Swing, JDBC and Maven.
- **MVC, DAO and Service-layer architecture**.
- Practical use of **Strategy and Observer patterns**.
- Relational database design and desktop application development.

**Portfolio value**
- Shows progression from Java syntax/OOP to structured, database-driven software.
